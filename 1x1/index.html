Como resolver o cubo 1x1

Você achou a página secreta! O 1x1 é o único cubo que já sai resolvido da caixa e continua resolvido, não importa o que você faça. Este é o guia completo, com todos os passos.

  1. Passo 1

    Segure o cubo

    Qualquer face para cima: no 1x1, todas são a de cima.

    Fórmula: (nenhuma)

  2. Passo 2

    Confira as faces

    Olhe as 6 faces: cada uma tem uma cor só. Se alguma tiver duas cores, você está segurando outra coisa.

    Fórmula: (nenhuma)

  3. Passo 3

    Pare o cronômetro

    Pronto. Seu tempo é o recorde mundial, empatado com todo mundo que já tentou.

    Fórmula: (nenhuma)

Erros comuns

Usar o método básico: são 8 passos para arrumar 0 peças fora do lugar. Decorar fórmulas: não há nenhuma. Gastar os 15 segundos de inspeção: você não vai precisar de nenhum.

Dica: pode girar as faces à vontade para aquecer os dedos. O cubo continua resolvido, mas cada giro deixa o seu tempo mais longe do recorde.

O cartão do 1x1

Para não faltar no baralho: imprima, recorte e guarde junto com os outros.
