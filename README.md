# CubingCards

**Cartões de estudo para o seu cubo, prontos para imprimir.** 🧩

👉 **https://cubingcards.com.br**

O CubingCards junta, em português, as fórmulas, as dicas e as explicações para aprender a resolver o cubo mágico, e
transforma tudo em cartões para imprimir, recortar e levar para treinar. Tem também cronômetro por caso, treino de
reconhecimento, notação, embaralhamentos e o seu progresso, tudo direto no navegador.

| Cubos | Métodos (no 3x3) | Para imprimir | Para treinar |
| --- | --- | --- | --- |
| 2x2, 3x3, 4x4, 5x5, Megaminx e Pyraminx | Método básico, CFOP (do 2-Look ao completo), Roux e ZZ | Cartões em folhas A4, com a imagem na frente e a fórmula no verso | Cronômetro por caso, reconhecimento, cruz, notação e PLL de 2 lados |

## O que tem neste repositório

Só o site **já compilado**: os arquivos HTML, CSS, JavaScript e as imagens que o GitHub Pages publica em
cubingcards.com.br. Eles são gerados automaticamente a cada atualização, então:

- não adianta editar os arquivos daqui (a próxima publicação apaga a mudança);
- pull requests não são aceitos;
- o histórico deste repositório não guarda as versões anteriores.

O código-fonte fica num repositório privado.

## Como contribuir

A contribuição é pelas **[issues](https://github.com/danielcorvello/cubingcards/issues)**. Toda ajuda é bem-vinda:

- **Achou um erro?** Fórmula que não resolve o caso, imagem trocada, texto com erro, botão que não funciona.
- **Tem uma fórmula melhor?** Uma fórmula mais rápida, mais fácil de lembrar ou com outro ângulo de pegada.
- **Sentiu falta de algo?** Um caso, um método, uma explicação ou um cubo que ainda não está no site.
- **Uma ideia para o site?** Sugestões de páginas, de treinos ou de jeitos de imprimir.

Para a gente achar o problema rápido, conte na issue:

1. **o endereço da página** (por exemplo, `https://cubingcards.com.br/3x3/pll/t`);
2. **o que está errado** e **o que você esperava**;
3. no caso de fórmula, **a fórmula** e **em que ângulo** você segura o cubo;
4. se for um problema na tela, **o navegador** e **o aparelho** (celular, computador), e um print, se puder.

Antes de abrir, dê uma olhada se já não existe uma issue sobre o mesmo assunto; se existir, comente nela.

## Perguntas comuns

**Meus dados (progresso, fórmulas escolhidas) ficam onde?**
No seu navegador mesmo (localStorage). Nada vai para um servidor. Para passar para outro aparelho, use
"Exportar" e "Importar" na página **Meu progresso**.

**O site usa cookies?**
Só o Google Analytics, para saber quais páginas são usadas, e só se você clicar em "Aceitar". Detalhes em
[cubingcards.com.br/privacidade](https://cubingcards.com.br/privacidade).

**Os cartões não saíram no tamanho certo na impressão.**
Imprima em **tamanho real** (100%, sem "ajustar à página"). A página de calibração da impressão ajuda a conferir a
sua impressora.

**De onde vêm as fórmulas?**
De várias fontes da comunidade, citadas na página [Sobre](https://cubingcards.com.br/sobre). Obrigado a quem as
reuniu e publicou.

## Apoie
