Notação do Pyraminx

Cada letra é uma ponta da pirâmide. A maiúscula gira a ponta e a camada abaixo dela; a minúscula, só a pontinha. O apóstrofo (') inverte o sentido.

Como segurar

Segure com uma face de frente para você e uma ponta para cima. Para embaralhar, como nas competições da WCA, o verde fica na frente e o amarelo embaixo.

  • As letras são as pontas, não as faces: U é a de cima, L e R são as duas de baixo, na frente (à esquerda e à direita), e B é a de trás, escondida atrás do Pyraminx, embaixo.
  • Maiúscula ou minúscula: U, L, R e B giram a ponta e a camada abaixo dela; u, l, r e b, só a pontinha.
  • O sentido: horário é olhando para a ponta de frente, como se ela apontasse para você. O apóstrofo (') inverte.
  • Sem o 2: cada giro é 1/3 de volta (120°). Dois giros para um lado dão no mesmo que um para o outro (U U é o mesmo que U'), por isso não existe U2.
